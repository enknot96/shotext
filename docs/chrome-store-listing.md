# Chrome ウェブストア掲載用テキスト / Chrome Web Store Listing Copy

Chrome Web Store Developer Dashboard の「ストアの掲載情報」にそのまま貼り付けて使えます。

## 短い説明（要約）/ Short description

manifest.jsonの`description`と同じものを使用（132文字制限）。

```
範囲を選択してOCR、結果をクリップボードにコピー / Select an area, OCR it, and copy the text to your clipboard.
```

## Detailed description (English)

```
While following along with programming tutorials on YouTube, I kept hitting the same annoying snag: the video would show a long AI prompt on screen, but the text itself was never provided anywhere. I'd end up taking a screenshot, uploading it to Claude, and asking it to transcribe the text — over and over again. I figured there had to be an easier way, and that's how ShoText！was born.

ShoText！lets you drag-select any area of a web page, automatically OCRs it, and copies the recognized text straight to your clipboard.

■ How to use
1. Press Alt+Shift+D
2. Drag to select an area containing text
3. Wait a moment — the recognized text is automatically copied to your clipboard (a toast notification confirms the copy)
4. Paste it wherever you like

■ Features
- Fully automatic: select an area, OCR runs, and the text lands in your clipboard
- Supports both Japanese and English
- OCR runs entirely inside your browser (Tesseract.js / WebAssembly) — nothing is ever sent to a server
- No saving or uploading required — just select and paste

■ Privacy
This extension never sends your selected image anywhere. All recognition happens locally in your browser.
```

## 詳細説明（日本語）

```
YouTubeのプログラミング解説動画を見ながら写経していたとき、動画内でAIに渡している長いプロンプトがどこにも配布されておらず、画面をスクショしてClaudeにアップロードし、文字起こしする…という地味な作業を何度も繰り返していました。「これ、もっと簡単にできるはずだ」と思ったのが、ショッテキ！を作ったきっかけです。

ショッテキ！は、画面の好きな範囲をドラッグで選択するだけで、その中の文字を認識し、クリップボードにコピーしてくれるChrome拡張機能です。

■ 使い方
1. Alt+Shift+D を押す
2. 文字を含む範囲をドラッグで選択する
3. 少し待つと、認識されたテキストが自動でクリップボードにコピーされます（コピー完了はトースト通知でお知らせします）
4. あとは好きな場所に貼り付けるだけ

■ 特徴
・範囲選択→OCR→クリップボードコピーまで完全自動
・日本語・英語の両方に対応
・OCRはすべてブラウザ内（ローカル）で実行。画像やテキストが外部サーバーに送信されることはありません
・保存やアップロードの手間なし。選んで貼るだけ

■ プライバシーについて
このツールは選択した範囲の画像を一切外部に送信しません。認識処理はすべてお使いのブラウザ内（Tesseract.js／WebAssembly）で完結します。
```
